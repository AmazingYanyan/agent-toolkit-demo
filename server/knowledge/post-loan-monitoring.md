# 贷后监控与风险预警处置（虚构）

> **重要声明：本文档为教学演示用虚构材料，不代表真实的贷后管理制度。**

## 一、贷后检查频次

一般客户原则上每季度至少检查一次；关注类客户每月检查一次；出现预警信号的客户应在五个工作日内完成首次专项检查。检查方式包括现场走访、财务资料收集、账户流水分析和外部信息查询。

## 二、预警信号分类

预警信号分为财务信号、经营信号、管理信号和外部信号四类。财务信号包括收入骤降、应收账款异常增长、现金流连续为负；经营信号包括主要客户流失、产能闲置、订单取消；管理信号包括实际控制人变更、核心团队离职、股权质押比例过高；外部信号包括涉诉、行政处罚、被列入经营异常名录。

## 三、预警等级与响应

预警分为蓝色提示、黄色关注、橙色预警和红色预警四级。蓝色由客户经理跟进核实；黄色需制定风险化解方案并报备；橙色应暂停新增授信并启动压降；红色应立即启动资产保全程序，包括追加担保、提前收贷和诉讼准备。

## 四、账户资金监控

应关注客户在本行的账户流水变化，包括日均存款余额下降、大额资金异常流出、回款账户变更等情况。资金归行率持续下降往往是客户经营或合作意愿恶化的早期信号。

## 五、风险处置原则

处置应遵循"早发现、早干预、早处置"原则。对暂时性困难但基本面尚可的客户，可通过调整还款安排、追加担保等方式化解；对基本面恶化、还款意愿不足的客户，应及时采取法律手段，避免错过最佳处置窗口。

## 六、检查记录要求

每次贷后检查应形成书面记录，内容包括检查时间、方式、发现的问题、判断结论和后续措施。记录应可追溯，作为后续风险分类调整和授信决策的依据。

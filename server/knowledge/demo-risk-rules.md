# 演示财务风险提示规则（虚构）

> **重要声明：本文档为教学演示用虚构材料，不是北京农商银行的真实制度、办法或审查政策，不得用于任何真实业务判断。**

## 一、适用范围

本规则仅适用于"AI 与 Agent 技术原理演示平台"中的两家虚构企业（DEMO001 星河科技、DEMO002 晨光制造），用于演示知识库检索、规则判断与模型解释之间的分工关系。

## 二、资产负债率提示规则

资产负债率 = 总负债 ÷ 总资产 × 100%。

当资产负债率**高于 70%** 时，系统应提示"偿债压力关注"，并建议补充核实企业的短期借款到期结构与对外担保情况。

当资产负债率处于 50% 至 70% 之间时，不触发提示，但应在分析中列出该指标数值。

## 三、营业收入变动提示规则

营业收入同比变动率 = （本期营业收入 − 上期营业收入）÷ 上期营业收入 × 100%。

当营业收入**同比下降超过 15%**（即变动率低于 −15%）时，系统应提示"经营变化关注"，并建议核实收入下降的原因属于行业性波动、客户集中度变化还是订单流失。

同比增长或降幅在 15% 以内时不触发提示。

## 四、经营现金流提示规则

当经营活动产生的现金流量净额**小于 0** 时，系统应提示"现金流关注"，并建议结合应收账款周转情况判断是否为阶段性垫资。

经营活动现金流净额为正时不触发提示。

## 五、结论使用限制

1. 命中上述任一提示规则，仅代表该指标达到观察阈值，**不代表企业已经发生信用风险**。
2. 本规则不构成授信审批结论，不得据此直接作出否决或压降决定。
3. 指标计算应由确定性程序完成，模型只负责解释与表达，不应由模型自行判断阈值是否满足。

## 六、数据口径与版本

演示财务数据统一以"万元"为单位，数据版本为 demo-2026.10-v1，数据来源为本地演示库。每次运行都会记录所使用的数据版本，以保证不同能力配置下的结果具有可比性。

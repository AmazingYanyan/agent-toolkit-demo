# 现金流分析方法

## 一、三类现金流的含义

| 类别 | 含义 | 关注点 |
|---|---|---|
| 经营活动现金流 | 日常经营产生的现金净流入 | 是否为负、是否持续为负 |
| 投资活动现金流 | 购置与处置长期资产 | 大幅流出可能是扩张，也可能是维持性支出 |
| 筹资活动现金流 | 借款、还款、股东投入与分红 | 经营现金流为负时是否靠借款维持 |

演示数据只提供经营活动现金流量净额，因此**只能分析经营现金流**，不得推断投资与筹资活动。

## 二、经营活动现金流为负的含义

经营活动现金流为负，说明当期经营性现金流出大于流入。常见原因：

1. **收入下降导致回款减少**——与利润下滑同步出现。
2. **应收账款回收放缓**——收入未降但现金未回。
3. **存货积压占用资金**——采购付现但未形成销售。
4. **集中支付应付款或税费**——属于时点性因素。

这四类原因的处理方式完全不同，缺少应收账款、存货、应付款数据时，只能列为"待核实原因"，不能选定其中一种作为结论。

## 三、判断逻辑

1. 经营现金流为负且净利润为正，属于"有利润没现金"，需重点关注回款质量。
2. 经营现金流为负且营业收入下降，属于"量价与回款同时走弱"，压力更直接。
3. 单年为负不一定构成问题，**连续两年为负**才具有较强指向性；本次只有一年数据，应说明局限性。
4. 现金流量净额是期间数，不是时点数，不能与资产负债表的时点数据直接相加比较。

## 四、常见误判

- **把现金流为负等同于亏损**：折旧摊销、营运资金变动都会造成差异。
- **忽略季节性**：批发零售、建筑施工类企业的现金流有强季节性，单季数据不具代表性。
- **用期末货币资金代替现金流**：货币资金余额可能包含受限资金（保证金、冻结存款），演示数据未提供该信息。

## 五、输出要求

- 必须写明现金流为负的**期间**与**金额**，不得只写"现金流紧张"。
- 必须写明"原因待核实"以及核实所需的数据项。
- 不得用经营活动现金流替代偿债能力结论。

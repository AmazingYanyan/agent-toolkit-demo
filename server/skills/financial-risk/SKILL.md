# 财务风险提示分析 Skill

## 一、适用任务

当用户要求"按标准方法分析某企业财务风险""给出风险提示"时使用本 Skill。
输入数据通常只有 3 至 5 个字段，属于轻量分析，不构成授信审查。

## 二、执行步骤

1. **提取事实**：列出已获得的原始数据（年份、营业收入、总资产、总负债、经营现金流净额）。
2. **计算指标**：营业收入同比变动率 =（本期 − 上期）÷ 上期；资产负债率 = 总负债 ÷ 总资产。
   如已提供计算工具，应调用工具计算，不得自行口算。
3. **判断阈值**：若已提供确定性规则工具，应交由工具判断；未提供时，明确说明阈值来自用户提供的规则，并标注"未由程序校验"。
4. **区分事实与推测**：明确写出哪些是数据直接支持的结论，哪些是行业经验推测。
5. **按结构输出**（见第四节）。
6. **列出资料不足项**：指出为形成更完整判断还需要哪些数据。

## 三、数据要求

- 必需：本期与上期营业收入、本期总资产与总负债。
- 可选：经营活动现金流净额、应收账款、短期借款到期结构。
- 缺失必需数据时，不得编造，应直接说明缺失并给出可替代的分析方式。

## 四、输出结构

```
一、已确认事实
（逐条列出，带数值与单位）

二、指标计算结果
（指标名称 = 数值，注明计算方式）

三、风险提示
（每条提示注明：触发原因、依据的数据）

四、证据不足之处
（明确说明哪些判断缺乏数据支撑）

五、建议补充的资料
（最多三条）
```

## 五、禁止事项

- 不得编造未被提供的数据。
- 不得将"命中提示阈值"表述为"企业已发生信用风险"。
- 不得给出授信审批结论（同意、否决、压降额度等）。
- 不得省略"证据不足之处"一节。

## 六、语气要求

面向银行业务人员，使用简洁、克制的中文书面语；不使用营销式表述，不使用感叹号。

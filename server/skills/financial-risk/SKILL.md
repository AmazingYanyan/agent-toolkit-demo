# 财务风险提示分析 Skill

本文件是**入口与路由**，不是全部内容。具体方法论拆在 `references/`，确定性计算放
`scripts/`，输出模板放 `assets/`。只有任务确实需要时，才去读取或执行对应资源。

## 一、适用任务

当用户要求"按标准方法分析某企业财务风险""给出风险提示"时使用本 Skill。
输入数据通常只有 3 至 5 个字段，属于轻量分析，不构成授信审查。

## 二、执行步骤

1. **校验输入**：先确认必需字段是否齐全。若已提供 `run_skill_script`，用
   `validate_data.py` 校验，不要凭印象判断数据够不够。
2. **提取事实**：列出已获得的原始数据（年份、营业收入、总资产、总负债、经营现金流净额）。
3. **计算指标**：营业收入同比变动率 =（本期 − 上期）÷ 上期；资产负债率 = 总负债 ÷ 总资产。
   必须调用 `run_skill_script` 执行 `calculate_ratios.py`，不要自行口算，也不要读取脚本源码。
4. **选择分析方法**（按需读取，不要一次全读）：
   - 涉及资产负债率、偿债能力、流动性 → 读取 `references/solvency.md`
   - 涉及收入变动、毛利率、盈利质量 → 读取 `references/profitability.md`
   - 涉及经营活动现金流、现金流为负、资金链 → 读取 `references/cashflow.md`
   - 需要指标定义或口径说明 → 读取 `references/indicator-guide.md`
   - 需要输出格式与措辞模板 → 读取 `assets/report-template.md`
5. **区分事实与推测**：明确写出哪些是数据直接支持的结论，哪些是行业经验推测。
6. **按结构输出**（见第四节）。
7. **列出资料不足项**：指出为形成更完整判断还需要哪些数据。

## 三、数据要求

- 必需：本期与上期营业收入、本期总资产与总负债。
- 可选：经营活动现金流净额、应收账款、短期借款到期结构。
- 缺失必需数据时，不得编造，应直接说明缺失并给出可替代的分析方式。

## 四、输出结构

```
一、已确认事实
（逐条列出，带数值与单位）

二、指标计算结果
（指标名称 = 数值，注明由脚本计算得出）

三、风险提示
（每条提示注明：触发原因、依据的数据、依据的分析方法）

四、证据不足之处
（明确说明哪些判断缺乏数据支撑）

五、建议补充的资料
（最多三条）
```

## 五、禁止事项

- 不得编造未被提供的数据。
- 不得将"命中提示阈值"表述为"企业已发生信用风险"。
- 不得给出授信审批结论（同意、否决、压降额度等）。
- 不得省略"证据不足之处"一节。
- 不得把未读取的方法论写成"已查制度"。

## 六、语气要求

面向银行业务人员，使用简洁、克制的中文书面语；不使用营销式表述，不使用感叹号。

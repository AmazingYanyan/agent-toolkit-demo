# 特殊约定与风险条款清单

## 一、需要单独标注的六类特殊约定

| 类型 | 典型表述 | 风险点 |
|---|---|---|
| 排他条款 | "合作期内不得与第三方开展同类合作" | 限制后续业务空间 |
| 自动续期 | "期满未提出异议自动续展一年" | 易形成长期被动承诺 |
| 单方解约 | "甲方有权随时解除且不承担违约责任" | 权利义务不对等 |
| 无限责任 | "乙方承担一切损失" | 未设赔偿上限 |
| 加速到期 | "发生任一违约事件全部款项立即到期" | 触发条件过宽 |
| 最惠待遇 | "价格不高于其向任何第三方的报价" | 履约举证困难 |

## 二、核对动作

1. 出现上述表述时，先原文摘录，再标注类型，不要改写原意。
2. 判断是否需要提示修订：涉及金额敞口、期限承诺、排他范围的，一律提示。
3. 特殊约定不必然构成问题，结论应写成"需业务确认"，而不是"存在风险"。

## 三、前后一致性检查

- 付款比例合计是否等于 100%
- 生效日期是否不早于签署日期
- 合同期限与自动续期条款是否冲突
- 争议解决机构与适用法律是否指向同一法域
- 附件清单与实际附件是否对应

## 四、不得作出的判断

- 不得评价条款是否"公平"（属法律与商务判断）。
- 不得推断当事人真实意图。
- 不得引用未在合同中出现的口头约定。

## 五、输出要求

每条特殊约定单独成行，格式为：`序号 | 条款位置 | 类型 | 原文摘录 | 需确认事项`。

# 担保与保证条款核对口径

## 一、必须核对的位置

| 位置 | 核对内容 | 常见问题 |
|---|---|---|
| 保证人信息 | 名称、统一社会信用代码、法定代表人、住所 | 名称与营业执照不一致 |
| 保证方式 | 一般保证 / 连带责任保证 | 未写明，默认为一般保证，追偿难度更大 |
| 保证范围 | 主债权、利息、违约金、实现债权费用 | 漏写"实现债权的费用" |
| 保证期间 | 起算日、届满日 | 写"至主债务履行完毕"，实际等于无期限 |
| 抵押物 | 权属、评估值、抵押率、登记状态 | 未约定办理抵押登记的义务与时限 |
| 质押 | 质押物类型、交付或登记方式 | 以占有为要件的质押未约定交付 |

## 二、判断口径

1. **保证方式未明确时**，按《民法典》默认规则处理，但在核对结论中必须标注"未明确约定"，不得替当事人推断。
2. **保证期间早于或等于主债务履行期限**，视为约定不明，需要提示修订。
3. **抵押率** = 融资本息 ÷ 抵押物评估值。超过行内上限时应提示，但演示环境未接入正式上限标准，只能标注"需按行内标准复核"。
4. **反担保**是否存在、是否足值，应与主担保分开列示，不能合并成一条。

## 三、不得作出的判断

- 不得判断担保是否"足值"（缺少评估报告与抵押率上限）。
- 不得判断保证人是否具备代偿能力（缺少保证人财务报表）。
- 不得评价担保安排的商业合理性。

## 四、输出要求

每条核对结论必须包含：条款位置、原文摘录（不超过 60 字）、问题类型（缺失 / 表述不一致 / 需复核）、依据（本文件第几条）。
